# water-level-monitoring-system

## Project Description
The IoT Based Smart Water Level Monitoring System is designed to monitor the water level in a tank automatically using an HC-SR04 Ultrasonic Sensor and NodeMCU ESP8266.

It measures the distance between the sensor and water surface and indicates the water level through LEDs and a buzzer.

## Components Required
- NodeMCU ESP8266
- HC-SR04 Ultrasonic Sensor
- Red, Yellow and Green LEDs
- Active Buzzer
- Breadboard
- Jumper Wires
- Resistors
- USB Cable

## Software Requirements
- Arduino IDE
- ESP8266 Board Package
- Arduino C++

## Working
1. The ultrasonic sensor measures the distance from the water surface.
2. NodeMCU calculates the water level percentage.
3. Red LED indicates low water level.
4. Yellow LED indicates medium water level.
5. Green LED indicates high water level.
6. The buzzer alerts when the water level reaches approximately 90%.

## Applications
- Home Water Tanks

- Agricultural Water Tanks
